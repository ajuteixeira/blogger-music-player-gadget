# ![gif](https://pixels.crd.co/assets/images/gallery20/9254fefe.gif?v=29416114) Gadget de music player para o Blogger

Um player de música compacto, moderno e personalizável para ser integrado em sites, portfólios, blogs ou páginas pessoais.


## ![gif](https://pixels.crd.co/assets/images/gallery27/cbbf6424.gif?v=29416114) Como funciona

O widget conecta-se à API do YouTube em segundo plano para reproduzir o áudio de qualquer vídeo publicado na plataforma. Enquanto a mídia é executada de forma invisível, o usuário interage apenas com uma interface estilizada de player de áudio tradicional.

## ![gif](https://pixels.crd.co/assets/images/gallery20/49144169.gif?v=29416114) Funcionalidades

* **Reprodução contínua:** Toca o áudio do vídeo do YouTube sem exibir a janela de vídeo;
* **Controles do player:** Botões de Play, Pause, Avançar (+10s), Voltar (-10s) e Repetição em loop;
* **Barra de progresso Interativa:** Exibe a temporização exata (tempo decorrido e duração total) e permite avançar ou voltar a música clicando na barra;
* **Controle de volume:** Slider retrátil para ajuste suave de volume e recurso de mute;
* **Totalmente personalizável:** Permite trocar capa, título, artista e paleta de cores;
* **Leve e responsivo:** Construído de forma nativa (sem dependências externas), adaptando-se a qualquer tamanho de tela.


## ![gif](https://pixels.crd.co/assets/images/gallery24/a451831a.gif?v=29416114) Como configurar

1. **Escolha a música:** Defina o link do vídeo do YouTube que servirá como fonte do áudio;
2. **Defina as informações:** Adicione o link da imagem da capa, o título da faixa e o nome do artista;
3. **Ajuste as cores:** Modifique os códigos de cores no estilo do player para combinar com a identidade visual do seu site;
4. **Aplique no seu blog:** Cole o código em um gadget HTML/JavaScript do blogger.


## ![gif](https://pixels.crd.co/assets/images/gallery05/2cac36f2.gif?v=29416114) Tecnologias utilizadas
* HTML5 (estrutura);
* CSS3 (estilização flexbox e variáveis);
* JavaScript (lógica de progresso e volume);
* [YouTube IFrame Player API](https://developers.google.com/youtube/iframe_api_reference?utm_source=gemini&authuser=1) (motor de áudio).
